EXPERIMENTAL VOLUME DATA

Reading the vertical radar sample

What it shows

The left scale is beam height in km MSL, not height above the ground. Each coloured mark is the strongest return in a small local 3 by 3 radar-gate sample at one scan angle.

Colour key

below 35 dBZ 35–45 45–50 50–55 55+.

Hail clues

High dBZ alone is not proof of hail. The useful comparison is how high a 50–60 dBZ core reaches relative to the 0°C and −20°C temperature levels. A 50 dBZ core above −20°C, or a 60 dBZ core well above freezing, is more concerning than the same value low in the storm.

Important limitation

This is a distant, experimental volume-radar sample. It has gaps between scan angles, cannot see the lowest part of the storm here, and does not distinguish hail from very heavy rain on its own. It does not affect tracking, forecasts, or alerts.

Reference: NWS radar hail guidance.
